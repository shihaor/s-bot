# S-BOT

> **让每个人都能雇佣一群真正能干的 AI 同事。**
> 不是一个聊天窗口，而是一支会协作、会执行、会交付结果的 AI 团队。

S-BOT 是一个「AI 同事 + 真人」一起工作的桌面工作台。你可以创建多个有角色、有技能、有边界的智能体，把它们拉进群聊里和真人一起讨论、评审、拆任务，并让它们**真正动手**——读写文件、跑命令、把任务推进到完成。

---

## 为什么是 S-BOT

市面上的 AI 工具大多是「问一句、答一句」的聊天框。S-BOT 想解决的是另一个问题：

**把「问 AI」变成「和 AI 同事一起把事情做完」。**

- **有角色的 AI 同事**：产品经理、架构师、文案、数据分析……每个智能体有自己的职责、擅长和说话风格；
- **会协作**：群聊里多智能体顺序发言、互相评审、@ 真人拍板、冲突时主持人给结论；
- **能执行**：接 opencode 执行引擎，AI 不只是回一段话，而是真的读写文件、跑命令、交付产物；
- **真人在环**：AI 判定的完成、要动文件、要跑命令，都由真人确认。

> 用户不为「token」付费，为「事情做完了」付费。

## 开源与商业模式

S-BOT 采用 **Open Core** 模式，边界很清楚：

- ✅ **开源的部分**：本地工作台的全部客户端代码（智能体、群聊、任务、执行引擎集成、内网发现）。你可以 `clone`、`npm install`、`npm run dev`，立刻在本地跑起来，用你自己的 API Key 和智能体。
- 🔒 **不开源的部分**：「AI 同事市场」的服务端（雇佣、评价、托管、分成）。这是「雇佣成熟的 AI 同事」的价值所在，也是产品能持续迭代、作者能持续维护的现金流来源。

**协议**：`AGPL-3.0`。开源代码你可以自由使用、修改、再分发，但如果你基于它提供了网络服务，也需要以同样的协议开源你的改动——防止「拿来即用、闭源商用」的白嫖。

一句话：**代码送你，土壤给你，收成（雇佣市场）留给我们一起滚大。**

## 现在能做什么

一个可运行的垂直切片，从会话到多智能体执行全链路：

- 会话列表 / 消息历史 / 发送消息 / 流式输出（SSE）
- 多智能体顺序回复、`@` 指定智能体、中断、发言规则
- 工作台 / 任务（新建、编辑、完成、AI 判定完成 → @ 确认、群聊挂载）
- opencode 执行引擎：读写文件、跑命令、工具审批（允许一次 / 总是允许 / 拒绝）
- 知识库（RAGFlow）检索 + 引用角标
- 对话式创建智能体 / 技能 / 群聊工作流
- 真人成员、内网发现（飞秋式）、P2P 邀请、Mattermost 邀请
- 模型服务：主流厂商预设（DeepSeek / 千问 / OpenAI / Claude / Gemini / Kimi / 智谱 / 硅基流动 / Ollama），内置 URL 只填 Key，模型 ID 一键拉取
- 主题（亮/暗/跟随系统）、桌面通知、单实例、启动动画
- Windows 安装包（NSIS，含版本检测：降级红字警告 / 覆盖确认 / 升级提示）

## 快速开始

```bash
cd s-bot
npm install
npm run dev
```

打开 http://localhost:5173

**不配模型也能跑**：没填 `LLM_BASE_URL` 时用本地 mock 回复。

接真实模型：

```bash
cp .env.example .env
# 填 LLM_BASE_URL / LLM_API_KEY / LLM_MODEL
```

服务端启动日志会打印 `runtime llm · <模型名>`。

## 目录

```
s-bot/
├─ apps/
│  ├─ web/          React + Vite（三栏界面）
│  └─ desktop/      Electron 壳（打包 Windows 安装包）
├─ packages/
│  ├─ shared/       共享类型
│  └─ server/       Hono + SQLite + SSE + 模型调用
├─ scripts/dev.mjs  同时起 server 和 web
└─ .env.example
```

数据库默认在 `packages/server/data/sbot.db`（相对于服务进程工作目录）。

---

## 打包

```bash
cd apps/desktop
npm install
npm run build:main
npm run dist   # 出 release/S-BOT-Setup-<版本>.exe
```

内网环境下载依赖慢时，先配置镜像：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
```
