# S-BOT 使用手册

## 一、S-BOT 是什么

S-BOT 是一款本地优先、可内网私有化部署的 AI 协作桌面应用。你可以注册多个「智能体」（AI 同事），让它们单独和你聊，或者拉进「群聊」里一起讨论、评审、做任务；还可以和局域网里的真人同事直接聊天、协作。

## 二、首次使用

1. 第一次启动后，界面会提示「未配置模型」。先到「设置 → 模型」里配置一个大模型（如 DeepSeek）的 Base URL 和 API Key。
2. 配置好模型并设为默认后，智能体才能正常回答。
3. 消息列表里预置了一个「S-BOT 助手」，内置本使用手册，直接问它「怎么用」即可。

## 三、智能体

- 在「智能体」页面点「新建智能体」，填写名字、角色（人设）、颜色、擅长技能，可选绑定模型、知识库和技能。
- 人设写在「系统提示词」里，决定这个 AI 的说话风格和职责边界。
- 新建完成后会自动开一个单聊，出现在左侧消息列表，点开就能聊。

## 四、群聊

- 首页点「新建群聊」，拉 2~6 个智能体（或真人）进群，群里成员会围绕你的问题轮流发言、讨论、评审。
- 也可以在新建群聊时点「用对话生成」，用一句话描述目标，AI 会自动选智能体并生成聊天逻辑。

## 五、聊天逻辑图

- 每个群聊可以有一张「聊天逻辑图」，决定发言顺序：开始 → 智能体节点 → 评审/修订分支 → 真人确认 → 结束。
- 打开群聊详情，可以「编辑聊天逻辑」手动改，也可以「用对话生成」。
- 节点类型：开始、智能体（AI 发言）、真人确认（等真人拍板）、结束；连线条件：always / pass / changes / timeout。
- 流程跑完（出结论、你确认后）群会转成自由讨论，不再按流程重跑；需要再来一轮时点输入框上方的「重新按流程」。

## 六、任务

- 在群聊里把某条议题「转成任务」，或首页点「新建任务」；任务可设优先级、绑定到群、标记完成。
- 新建群后，第一条实质议题会被 AI 自动理解成任务并绑定到群。

## 七、知识库

- 在「设置 → 知识库」里配置 RAGFlow 数据集，并把它绑定到某个智能体。
- 绑定后，智能体回答时会用 [1][2] 这样的角标标注检索到的资料，点击角标可看原文。

## 八、让智能体真正执行

- 智能体可以把方案交给本机执行引擎去真正写代码、落地文件；首次使用会自动安装，已安装则复用。
- 涉及读写文件、执行命令等敏感操作前，会先征求你同意。

## 九、真人协作与内网发现

- 消息列表里的「真人」就是局域网里其他装了 S-BOT 的同事，点一下就能 1 对 1 聊天。
- 自动发现靠局域网广播；如果发现不了，就在「找同事」里把本机地址告诉对方，对方输入你的 IP 即可（端口固定 17070，无需填）。
- 群聊里用 @名字 可以点名让某个真人拍板。

## 十、常用操作

- 关闭窗口（点 X）：会弹出「最小化到托盘 / 退出 / 取消」的选择，最小化后可从托盘重新打开。
- 收到新消息时，左下角会弹出提示；消息未读时，对应联系人右侧会显示红点数字。
- 个人名字默认是「未知」，点左上角头像可以修改本地身份（名字/角色）。

## 十一、常见问题

- 智能体不说话？→ 检查是否已在「设置 → 模型」里配置并设为默认。
- 两台电脑互相发现不了？→ 先确认在同一个局域网，再用「找同事 → 手动添加」输入对方 IP。
- 流程怎么不按逻辑走了？→ 那是因为已经出结论了，群转成了自由讨论，点「重新按流程」即可再来一轮。
- 数据存在哪？→ 默认存本机应用数据目录的 sbot.db，本地优先。
